# Mini-3Dgame Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a playable browser third-person shooter with one player, five bots, and touch/PC controls.
**Architecture:** DOM-independent fixed-step simulation owns match state. Input produces commands; Three.js renders state; world geometry is shared by movement, navigation, bullets, and camera collision.
**Tech Stack:** JavaScript ES modules, Three.js, Vite, Node test runner, Playwright.
**Spec:** ../specs/2026-10-03-mini-3dgame-design.md

## Global Constraints
- One player and five bots; single-player only; future friends/1v1 are separate projects.
- 160 × 160 m world; buildings are solid cover, not enterable interiors.
- 100 HP; 30-round magazine; unlimited reserve; 1.8-second reload; 20 damage; 6 shots/second.
- Zone: radius 105; wait 30s, shrink to 55 over 60s, wait 20s, shrink to 20 over 60s, wait 20s, shrink to 0 over 45s. Outside damage: 5 HP/s.
- PC WASD/mouse/fire/aim/R/Shift/Escape; mobile joystick/look/fire/aim/reload/sprint.
- Pause on focus loss/tab hidden; clear held input; fresh state on restart.
- Pixel ratio cap 1.5; relative build assets; original procedural assets.
- No claim of actual phone performance without actual device measurements.
- UI copy in Mongolian, familiar weapon/control abbreviations allowed.
- Read repository AGENTS.md if present at execution. Work on an isolated feature branch and preserve user changes.

## Review Focus
1. Multiple simultaneous touch pointers: releasing look must not cancel movement or shooting (Task 4).
2. Backgrounding with fire held: resume must not fire until a new press (Task 4).
3. Camera sees around cover but muzzle is blocked: bullet must hit cover (Tasks 2 and 5).
4. Long frame stalls and simultaneous deaths: bounded simulation catch-up and deterministic defeat precedence (Task 2).
5. Repeated restart: no duplicate loops, handlers, bots, or accumulated damage (Task 6).

## File map and shared contracts
- package.json, package-lock.json, index.html, vite.config.js: scripts, pinned dependencies, entry, relative base.
- src/world.js: WORLD data, spawn positions and axis-aligned solid obstacles.
- src/collision.js: movement and ray collision; src/navigation.js: grid/A*.
- src/combat.js: weapon state and shots; src/simulation.js: state, zone, lifecycle.
- src/bots.js: AI commands using perception/navigation.
- src/input.js: DOM adapters plus testable pointer reducer.
- src/renderer.js: procedural scene, camera, actors and effects.
- src/ui.js, src/styles.css, src/main.js: screens, HUD and loop.
- tests/*.test.js: node simulation/input tests; tests/browser.spec.js: browser checks.
- playwright.config.js, README.md, .gitignore: browser setup and usage.
- .github/workflows/ci.yml: install, test, build on push/PR.

Use JSDoc contracts:
Vec3={x:number,y:number,z:number}; solid={min:Vec3,max:Vec3}.
Actor={id,pos:Vec3,yaw,hp,ammo,reloadLeft,shotCooldown,alive,isPlayer}.
Command={moveX,moveZ,yaw,pitch,fire,aim,reload,sprint}.
State={actors,time,status:'ready'|'playing'|'paused'|'won'|'lost',zoneRadius,events}.
Event={type:'shot'|'hit'|'death',actorId,position:Vec3}.
Coordinates: y up, world x/z horizontal; commands use world-space normalized movement.
Simulation dt=1/60; render frame delta cap 0.1s; drop excess accumulated time.
Player death takes precedence over win if all remaining actors die in the same tick.
