# Mini-3Dgame — эхний хувилбарын загвар
Огноо: 2026-10-03
Төлөв: Хэрэглэгч үндсэн санааг зөвшөөрсөн; энэ бичгээрх загварыг хянах шат.

## Зорилго
PUBG Mobile-ээс санаа авсан, өөрийн дүрслэлтэй жижиг 3D survival shooter.
Эхлээд нэг хүн таван ботын эсрэг тоглоно. Дараагийн тусдаа үе шатанд
найзуудтай хамт тоглох болон 1v1 нэмнэ. Эхний хувилбарт онлайн холболт,
бүртгэл, сервер, matchmaking орохгүй.

## Сонгосон шийдэл
Browser дээр ажиллах JavaScript, Three.js, Vite төсөл.
GitHub repository нь FGadaruugan/Mini-3Dgame. Статик build нь repository
дэд замаас ажиллах relative asset замтай байна.
Энэ нь одоогийн жижиг single-player хүрээнд тохирно. Бүхэл game engine
ашиглах нь export болон төслийн хэмжээг өсгөнө; raw WebGL нь шаардлагагүй
дүрслэлийн ажлыг нэмнэ. Сангуудын бодит хувилбарыг хэрэгжүүлэх үед шалгаж түгжинэ.

## Тоглолтын урсгал
Эхлэх дэлгэц → удирдлагын тайлбар → тоглолт → ялалт/ялагдал → дахин тоглох.
Нэг тоглогч, таван бот тусдаа аюулгүй байрлалд гарна.
Ботууд хоорондоо болон тоглогчтой тулалдана. Сүүлчийн амьд дүр тоглогч
байвал ялна; тоглогчийн HP тэг болбол ялагдана.
Дахин тоглоход сум, HP, бот, хугацаа, бүс, оролтын төлөв бүрэн шинэчлэгдэнэ.

## Газрын зураг ба дүрслэл
Ойролцоогоор 160 × 160 метрийн low-poly талбай; хоргодох барилга, хана,
мод, чулуу. Барилгууд эхний хувилбарт дотогш орохгүй битүү хоргодох
объект байна. Дүр болон сум хана нэвтрэхгүй. Газрын хилээс гарахгүй.
Өөрийн энгийн humanoid дүртэй, мөрний араас харах third-person камер.
Камерын хана нэвтрэлтийг collision ray-аар хязгаарлана.
Хөдөлгөөнд алхах animation; буудахад богино muzzle flash, hit feedback.
PUBG-ийн нэр, лого, дуу, asset хуулбарлахгүй.

## Удирдлага
PC: WASD хөдөлгөөн; mouse камер; зүүн товч буудах; баруун товч онилох;
R цэнэглэх; Shift гүйх; Escape pause/курсор суллах.
Утас: зүүн joystick; баруун дэлгэцээр камер эргүүлэх; тусдаа буудах,
онилох, цэнэглэх, гүйх товч. Хоёр болон түүнээс олон хуруугаар хөдөлж,
онилж, буудах боломжтой pointer-ID удирдлага.
Landscape байрлалд зориулсан HUD; portrait үед эргүүлэх санал харуулна.
Focus алдах эсвэл tab нуухад pause хийж, баригдсан input-уудыг цэвэрлэнэ.

## Тулааны эхний тохиргоо
Бүх дүр 100 HP. Нэг автомат буу: 30 сумтай magazine, хязгааргүй нөөц
сум, 1.8 секунд цэнэглэх хугацаа; нэг онолт 20 damage, секундэд 6 сум.
Цэнэглэж байхдаа буудахгүй; сумгүй үед цэнэглэх сануулга гарна.
Онилоход FOV багасаж, тархалт буурна. Hitscan ray нь эхний таарсан
хана/дүр дээр зогсоно. Камерын онилсон цэгийг бууны амнаас дахин
шалгаж, хоргодох хананы цаанаас сум нэвтрэхээс сэргийлнэ.
HUD: HP, сум, үлдсэн амьд дүрийн тоо, бүсийн хугацаа, crosshair,
онох feedback болон бүсийн гаднах анхааруулга.

## Бот
Patrol → detect → chase → attack → reposition төлөвүүд.
Харах зай болон line-of-sight шалгана; хана нэвт харж буудахгүй.
Хамгийн ойрын харагдах амьд дайсныг сонгож, бага reaction delay,
онилох алдаатай тулалдана. Collision grid ба A* замчлалаар
битүү саадыг тойрно; замыг тогтмол бага давтамжаар дахин тооцно.
Аюулгүй бүсээс гарвал дотогш орохыг эрэмбэлнэ.
Үхсэн бот хөдөлж, буудаж, damage авахгүй.

## Аюулгүй бүс
Төв нь газрын зургийн төв. Эхний радиус 105 м.
30 секунд бэлтгэл → 60 секундэд 55 м хүртэл агших →
20 секунд завсар → 60 секундэд 20 м хүртэл агших →
20 секунд завсар → 45 секундэд 0 м хүртэл агших.
Бүсийн гадна бүх амьд дүр секундэд 5 HP алдана.
Damage болон timer нь frame rate-аас хамаарахгүй.
Бүсийн хил газрын гадарга дээр ойлгомжтой харагдана.

## Кодын бүтэц
- main/UI: эхлэх, pause, үр дүн, HUD; simulation state-ийг уншина.
- input: PC ба touch оролтыг ижил хөдөлгөөн/онилгооны command болгоно.
- simulation: дүрийн төлөв, fixed timestep, match lifecycle, zone.
- combat: сум, cooldown, reload, hit болон death дүрэм.
- bots/navigation: шийдвэр, харагдац, grid pathfinding.
- world/collision: газрын зураг, spawn, хөдөлгөөний саад.
- renderer: Three.js scene, камер, animation, effects.

Simulation нь DOM-оос хамаарахгүй; renderer state-ийг уншина.
Дараа онлайн нэмэхэд authoritative server, state sync, latency handling
тусад нь хэрэгжинэ. Энэ бүтэц дангаараа multiplayer бэлэн гэсэн үг биш.

## Алдаа ба гүйцэтгэл
WebGL байхгүй эсвэл renderer үүсэхгүй бол ойлгомжтой алдаа харуулна.
Render loop нэг удаа үүснэ; restart үед event handler давхардахгүй.
Том frame delta-г хязгаарлана. Mobile pixel ratio-г 1.5-аар хязгаарлаж,
энгийн материал, хязгаарлагдмал effect, shared geometry хэрэглэнэ.
Бодит утсан дээр хэмжээгүй FPS-ийг баталгаатай гэж мэдэгдэхгүй.

## Шалгах нөхцөл
- Production build амжилттай; asset зам repository дэд замд ажиллах.
- Тоглолт эхлэхэд 1 тоглогч + 5 бот, HUD зөв харагдах.
- PC болон touch-оор хөдөлж, камераа эргүүлж, буудаж, reload хийх.
- Дүр, камер, буудлага ханатай зөв харьцах.
- Бот хана нэвт буудахгүй, саадыг тойрох.
- Reload/cooldown, HP, zone damage, ялалт/ялагдлыг simulation тестээр шалгах.
- Pause/resume болон restart төлөвийг зөв сэргээх.
- Desktop/mobile viewport дээр browser smoke test; боломжтой бол
  бодит төхөөрөмжийн шалгалт, хийгдээгүй бол хязгаарлалтыг тайлагнах.

## Дараагийн үе шат
Энэ хувилбарыг тоглож баталсны дараа онлайн 1v1-ийн тусдаа загвар гаргана.
Дараа нь найзуудтай хамт тоглох горимыг тодорхойлно.
