# Mini-3Dgame online profile setup

The repository contains the frontend and database schema for:

- Google sign-in
- automatic unique 8-digit Player ID
- friend requests by Player ID
- friends list
- realtime online presence
- online friend match invites

## 1. Use a dedicated Supabase project

Do not reuse an unrelated production project unless you intentionally want the data mixed.

Run `supabase/schema.sql` on the project.

## 2. Fill browser config

Open `supabase-config.js`:

```js
export const SUPABASE_URL = 'https://ozbcmjcawpnbxfnkvscd.supabase.co';
export const SUPABASE_PUBLISHABLE_KEY = 'sb_publishable_NwsEZxIt2CUhhf3SMzkhbA_-ZIoxVVm';
```

Only use a publishable/anon key in browser code. Never commit a service-role key.

## 3. Configure Google OAuth

In Google Auth Platform create a Web OAuth client.

Authorized JavaScript origin:

```
https://fgadaruugan.github.io
```

In the Google client, add the Supabase callback URL shown by the project's Google provider settings.

Enable Google in Supabase Auth and set the Client ID + Client Secret.

Set the Supabase Site URL / redirect allow list to include:

```
https://fgadaruugan.github.io/Mini-3Dgame/
```

## 4. Test

1. Open the game.
2. Tap the profile area or Friends icon.
3. Sign in with Google.
4. A unique 8-digit Player ID is generated by the database trigger.
5. On another account, enter that ID and send a friend request.
6. Accept the request.
7. When both accounts are online, INVITE becomes enabled.
